All notable changes to this project will be documented in this file.

## [0.1.0]

- Initial public release of the Verbex Python SDK.
- Modular client layout with `core`, `agents`, `tools`, `calls`, `knowledge_bases`, `phone_numbers`, `public_sharing`, `prompt_generation`, and `api_keys`.
- Documentation set in `docs/` plus `README.md` quick start and `CONTRIBUTING.md`.
- Ruff and pytest tooling with Git hooks.
